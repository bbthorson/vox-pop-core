## What's intentionally not here

This is infrastructure, not a finished app. Higher-level, product-specific features — IVR / call-forwarding, hosted embed-widget distribution, team and billing — aren't part of the open core; they live in the closed-source layer that runs [voxpop.com](https://voxpop.com), one of the apps built on this core.

Want to see the end-user side of a real app built on the core? voxpop.com's [help center](https://voxpop.app/help) documents recording prompts, managing replies, and sharing embeds.
